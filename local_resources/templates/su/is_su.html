{% comment %} The warning shown while an administrator is signed in as another user with django-su. Replaces coldfront's su/is_su.html, which only names the user signed in as. request.signed_in_by is the administrator, set by coldfront_utils.task_context's ActingUserMiddleware. Where that isn't installed or is older, it's missing, and this falls back to coldfront's wording. With it installed, what the administrator changes is recorded under their own name, with a note that they were signed in as the user: the banner says so, so nobody expects it to look like the user did it. The classes are django-hijack's, styled in common.css, as coldfront's template has them. {% endcomment %} {% if IS_SU %}
