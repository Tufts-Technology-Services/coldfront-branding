{% comment %} The tufts_local plugin's "View as" control, for a superuser on a project or allocation detail page. It sits in the breadcrumb row's right-hand block, before Notifications, and adds nothing to the row itself: included from project/detail/breadcrumbs.html and allocation/detail/breadcrumbs.html. That block is a .breadcrumb, which wraps, and is only col-3 wide, so the control is narrow: an eye icon, with the words only at xl widths, and the full wording as a tooltip and for screen readers. view_as comes from the plugin's context processor and is missing where the plugin isn't installed, so nothing shows there. It has people only on those two pages, only for superusers, and only while not already viewing as someone. They are at most three, one of each kind that can see a page differently: the project's PI, a manager who isn't the PI, and a user. Starting is a POST: it signs the superuser in as them, read-only, through django-su, for every page until they release them from the banner (su/is_su.html), which brings them back to the page they are on. The plugin gives each person's kind in coldfront's words: "pi", "manager" or "user". The words shown are this site's, the same ones project_detail.html uses: Owner for the PI, Approver for a manager.
